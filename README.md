# Neural Style Transfer

This project implements Neural Style Transfer using a pretrained VGG19 network.
It applies the artistic style of one image to the content of another.

## Technologies Used
- PyTorch
- VGG19
- Computer Vision

## How to Run
1. Place content image in `data/content/`
2. Place style image in `data/style/`
3. Run:
   >python run.py
